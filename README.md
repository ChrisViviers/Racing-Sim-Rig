DIY Sim Racing Wheel (Raspberry Pi Pico 2 + Adafruit AS5600)A high-precision, zero-friction USB Sim Racing Steering Wheel built using a Raspberry Pi Pico 2WH (RP2350), an Adafruit AS5600 magnetic rotary encoder over $\text{I}^2\text{C}$, custom tactile buttons, and a T8 CNC lead-screw shaft assembly.This project maps the 12-bit contactless Hall-Effect rotational data ($0-4095$) down to a clean, unsigned 8-bit HID Gamepad packet ($0-255$) running at 100Hz on CircuitPython.📸 Overview & FeaturesContactless Precision: Uses the Adafruit AS5600 magnetic sensor to read a diametrically magnetized magnet—no potentiometers to wear out or drift over time.4,096 Steps of Resolution: Smooth $360^\circ$ rotational tracking mapped directly to an unsigned USB HID axis.RP2350 Microcontroller: Powered by the Raspberry Pi Pico 2WH running CircuitPython.8 Integrated Inputs: Support for 8 tactile push buttons / paddle shifters with internal pull-up resistors.Zero Additional Software Needed: Enumerates directly as a standard USB Gamepad recognized by games like RaceRoom, Assetto Corsa, and iRacing.🛠️ Hardware Bill of Materials (BOM)ComponentQuantityDescription / NotesRaspberry Pi Pico 2WH1RP2350 microcontroller running CircuitPythonAdafruit AS5600 Breakout112-bit $\text{I}^2\text{C}$ Magnetic Rotary EncoderDiametric Magnet1Neodymium disc magnet (Must be diametrically magnetized)300mm T8 Shaft & Bearing Kit1Lead screw, pillow-block bearings, and shaft couplerTactile Buttons / Switches8Inputs for wheel buttons and paddle shiftersBreadboard / Custom PCB1Circuit interconnects🔌 Pinout & Wiring Diagram1. 🔧 Calibration & TroubleshootingThe "No Right Turn" Bug & Unsigned BytesWindows DirectX input interfaces expect unsigned byte alignment for custom HID axes. The math in scale_wheel() shifts the raw 12-bit sensor range ($0-4095$) so that dead-center sits locked at 127. Turning left decreases toward 0, while turning right increases up to 255.Windows Registry Profile ResetIf you previously plugged the Pico in with buggy descriptor math, Windows may cache the old hardware profile in its registry. To force a clean hardware re-read:Unplug the Pico 2.Open cmd as Administrator and run:DOSreg delete "HKCU\System\CurrentControlSet\Control\MediaProperties\PrivateProperties\Joystick\OEM" /f
Open Device Manager, click View > Show Hidden Devices, and uninstall any greyed-out HID-compliant game controllers.Re-plug the Pico 2 and test using joy.cpl.📜 LicenseThis project is open-source and available under the MIT License.
